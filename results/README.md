# Results

`test_finetuned.json` and `challenge_finetuned.json` are the released fine-tuned evaluation scores. `test_zero_shot.json` and `challenge_zero_shot.json` are the released Gemma-4-E4B baseline scores. `dev_history.json` records development macro scores at checkpoints 2,500, 3,000, and 3,500; `best.json` identifies checkpoint 3,000 as the released adapter.
