# Security policy

## Supported versions

The latest release on `main` is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security-sensitive reports. Email
the maintainers listed in `CITATION.cff` or use GitHub's private vulnerability
reporting feature. Include a description, reproduction steps, and impact.

This project loads third-party model weights and datasets. Only use
checkpoints from the sources documented in the README, and review remote code
flags before enabling them.
